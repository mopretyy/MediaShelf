# MediaShell — дизайн-роадмап

Задача владельца (2026-11-07): «улучши дизайн сайта в разы, сделай его самым пиздатым, добавь идей, всё записывай» — владелец скоро переходит на другой аккаунт, поэтому всё состояние работы лежит здесь и в `HANDOFF.md`.

**Как продолжать:** прочитать этот файл целиком, взять первый пункт со статусом «не начато» из таблицы ниже, сделать его отдельной веткой `tembo/design-…`, PR → зелёный CI → слияние, отметить статус здесь же. Скриншоты всех страниц: `docs/design/tour.mjs` (инструкция в шапке файла).

## Принципы (не нарушать)

`DESIGN.md` остаётся законом: строгий чёрно-белый интерфейс, цвет приходит только из постеров, фонов и аватарок, без цветных свечений, стекло только на плавающих слоях, тонкие линии вместо теней. «В разы лучше» значит больше кино и меньше «админки» внутри этой системы, а не перекраска:

- **Кадр важнее текста.** Там, где сейчас начинается текст, должен начинаться кадр: фон тайтла, постеры, крупная типографика поверх.
- **Каждая карточка с картинкой.** Никаких серых пустых прямоугольников: нет фона — берём размытый постер.
- **Одно главное действие на экран.** Крупно, рядом с кадром: «+1 серия», «Продолжить», «Добавить».
- **Движение со смыслом.** Плавные переходы 150–250 мс, никаких подпрыгиваний; всё уважает «уменьшить движение».
- **Мобильная версия — первая.** Всё проверяется на 320–430 px.

### Спецификация №1 — кино-герой на Главной

- Источник: первый элемент «Продолжить» (самый свежий тайтл в процессе). Нет такого — первый тайтл из «Популярного» выбранной категории.
- Кадр: `backdrop`, иначе размытый постер (как в №2). Высота 360–440 px на компьютере, 420–480 px на телефоне; градиент снизу и слева, как у героя тайтла; всегда тёмная палитра (`.dark`), как герой тайтла.
- Поверх: маленькая подпись («Продолжить» / «Популярное сейчас»), приветствие «Добрый день, Влад» крупно, название тайтла, строка прогресса (S5 · E9 · название серии / 75 %), кнопки: главное действие (для серий «+1 серия», для игр и фильмов «Открыть»), второе — «Все в процессе» / «Обзор».
- Строка поиска и чипы категорий остаются сразу под героем.
- Доступность: герой — `section` с заголовком h1 (приветствие), картинка декоративная (`alt=""`), кнопки обычные, без автопрокрутки.
- «Уменьшить движение»: без появления с увеличением.
