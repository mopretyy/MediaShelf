# Промо-ролик MediaShell (30 секунд)

Абстрактный рекламный ролик: 1920×1080, 30 кадров/с, 30 секунд, со звуком.

Файл: [`mediashell-promo-30s.mp4`](mediashell-promo-30s.mp4)

## Идея

Монохромный мир MediaShell: стена «постеров» без картинок, только цвет, как в самом приложении (цвет даёт контент, интерфейс остаётся чёрно-белым). На дропе трека стена вспыхивает цветом и собирается в логотип. Дальше пять коротких сцен в стиле панели приложения: статусы, «+1 серия», жребий, статистика и финальная карточка со ссылкой на репозиторий.

| Время     | Сцена                                                   |
| --------- | ------------------------------------------------------- |
| 0–4,3 с   | «Игры. Фильмы. Сериалы. Аниме.» на серой стене постеров |
| 4,3–8,5 с | Дроп: вспышка, цвет, логотип и слоган                   |
| 8,5–12,8  | Пять статусов (глифы из приложения)                     |
| 12,8–17,1 | «+1 серия»: сетка серий и прогресс                      |
| 17,1–21,4 | Жребий: барабан замедляется за 2,6 с, как в приложении  |
| 21,4–25,6 | Статистика года                                         |
| 25,6–30   | Логотип, преимущества, ссылка на GitHub                 |

Сцены сменяются точно по тактам трека (112 BPM, смена каждые 8 тактов, дроп на 4,27 с).

## Стиль

Всё взято из репозитория, без новых цветов и шрифтов:

- палитра и радиусы из `DESIGN.md` и `src/styles/index.css` (#0a0a0a, #141414, #1c1c1c, #ededed, #a1a1a1, линии белым 9 %);
- шрифт Inter Variable из `public/fonts`;
- логотип по геометрии `public/favicon.svg`;
- глифы статусов как в `DESIGN.md` (пунктир, половина, пауза, галочка, черта);
- цвета «постеров» сняты с постеров на скриншотах в `docs/screenshots`.

## Как пересобрать

Нужны Node.js 22+, FFmpeg и Chrome. Исходник — HTML-композиция [HyperFrames](https://hyperframes.heygen.com) в папке `source/`.

```bash
cd promo-video/source
npx --yes hyperframes@0.6.119 preview      # предпросмотр в браузере
npx --yes hyperframes@0.6.119 render --quality high --output ../mediashell-promo-30s.mp4
```

Тексты, тайминги и анимации находятся в `source/index.html`. Музыка, уже обрезанная и сведённая, лежит в `source/assets/music.mp3`. Источник и лицензия трека описаны в [CREDITS.md](CREDITS.md).
