# Промо-ролик MediaShell (30 секунд)

Абстрактный рекламный ролик: 1920×1080, 30 кадров/с, 30 секунд, со звуком.

Файл: [`mediashell-promo-30s.mp4`](mediashell-promo-30s.mp4)

## Идея

Монохромный мир MediaShell и полка настоящих обложек: фильмы, сериалы, аниме и игры вперемешку. Интерфейс чёрно-белый, цвет дают только обложки, как в самом приложении. До дропа полка приглушена и почти без цвета, на дропе вспыхивает цветом, и появляется логотип. Дальше пять коротких сцен в стиле панели приложения: статусы, «+1 серия», жребий, статистика и финальная карточка со ссылкой на репозиторий.

| Время     | Сцена                                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------------------------ |
| 0–4,3 с   | «Игры. Фильмы. Сериалы. Аниме.» на приглушённой полке обложек                                                      |
| 4,3–8,1 с | Дроп: вспышка, цвет, логотип и слоган                                                                              |
| 8,1–12,0  | Пять статусов (глифы из приложения)                                                                                |
| 12,0–15,9 | «+1 серия»: сетка серий и прогресс                                                                                 |
| 15,9–21,7 | Жребий: барабан из обложек замедляется за 2,6 с и останавливается на «Пиратах Карибского моря», GTA V и «Ведьмаке» |
| 21,7–25,6 | Статистика года                                                                                                    |
| 25,6–30   | Логотип, преимущества, ссылка на GitHub                                                                            |

Музыка: тёмный мелодик-техно в духе лейбла Afterlife, 124 BPM. Сцены сменяются на сильную долю: каждые 2 такта, жребию отдано 3 такта. Дроп приходится на 4,27 с.

## Стиль

Всё взято из репозитория, без новых цветов и шрифтов:

- палитра и радиусы из `DESIGN.md` и `src/styles/index.css` (#0a0a0a, #141414, #1c1c1c, #ededed, #a1a1a1, линии белым 9 %);
- шрифт Inter Variable из `public/fonts`;
- логотип по геометрии `public/favicon.svg`;
- глифы статусов как в `DESIGN.md` (пунктир, половина, пауза, галочка, черта);
- обложки взяты из тех же источников, что и в приложении: Cinemeta (фильмы и сериалы), Shikimori (аниме), Steam (игры). Они лежат в `source/assets/covers`.

## Как пересобрать

Нужны Node.js 22+, FFmpeg и Chrome. Исходник — HTML-композиция [HyperFrames](https://hyperframes.heygen.com) в папке `source/`.

```bash
cd promo-video/source
npx --yes hyperframes@0.6.119 preview      # предпросмотр в браузере
npx --yes hyperframes@0.6.119 render --quality high --output ../mediashell-promo-30s.mp4
```

Тексты, тайминги и анимации находятся в `source/index.html`. Музыка, уже обрезанная и сведённая, лежит в `source/assets/music.mp3`. Источник и лицензия трека и обложек описаны в [CREDITS.md](CREDITS.md).
